# open-inflation

The Open Base-Money Evidence Repository ([GildedPleb/open-inflation](https://github.com/GildedPleb/open-inflation)).

Simple time-series CSVs of global base money, where every observation is backed by a human-traversable, append-only Markdown evidence chain. Heavy artifacts stay external (archive.org); this repository holds only text.

Status: Waypoint 1, the skeleton and lint suite. There is no data yet.

## Layout

| Path                                       | What it is                                                                             |
| ------------------------------------------ | -------------------------------------------------------------------------------------- |
| `base_money.csv`                           | `date,value,evidence_id`: quarter-end date, integer USD, path to the quarterly roll-up |
| `evidence/base_money/YYYYQn.md`            | Quarterly roll-up: summary table, component anchors, machine-readable arithmetic block |
| `issuers/<ISS>/<YYYY>.md`                  | Append-only extracts per issuer and year, one `## YYYYQn` heading per quarter          |
| `INDEX.md`                                 | Entry point; links every roll-up and issuer-year file                                  |
| `catalog.json`                             | Series metadata and file paths                                                         |
| `methodology/`                             | How the numbers are defined and built                                                  |
| `scripts/lint.ts`                          | All integrity checks                                                                   |
| `scripts/update.ts`, `scripts/backfill.ts` | Waypoint 3 and 4 entry points (not implemented yet)                                    |

## Run it

Requires Bun 1.4 and git ([Bun](https://bun.sh); lint reads the tree and its base commit through git, so work in a clone).

```sh
bun install
bun test          # offline unit tests with fixtures; about 1 second; the merge gate
bun run lint      # integrity checks on this repository
```

`bun run lint` compares the working tree with a base commit: `$LINT_BASE` if set, otherwise `HEAD`. Pass `--base <ref>` to choose another. Its only network use is for archive URLs that the diff adds, and only ones that pass L7: one HEAD request to the snapshot at `https://web.archive.org/web/<timestamp>/<url>`, and, if web.archive.org is unreachable, one request to `https://archive.org/wayback/available` to confirm that exact snapshot timestamp. At most 4 requests run at once, each with a 15 s timeout. Links already committed are never re-checked. Offline, lint exits 1 when the diff adds an archive URL; that is intended. `bun install` may use the network; `bun test` never does. Research itself is not tested: `bun test` covers the software only.

Code checks: `bun run typecheck` and `bun run check` (format and code lint).

CI: `.github/workflows/lint.yml` runs all of the above on every push and pull request.

## What lint enforces

| Check | Rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L1    | `base_money.csv` is UTF-8 with no byte-order mark, LF line endings and a final newline; header exactly `date,value,evidence_id`; quarter-end ISO dates, strictly ascending; non-negative integer USD values                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| L2    | Every `evidence_id` is `evidence/base_money/YYYYQn.md`, exists, and matches the row's quarter                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| L3    | No committed heading in `issuers/` or `evidence/` is renamed or removed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| L4    | Committed lines in `issuers/` and `evidence/` are never changed or deleted. Committed CSV rows are never deleted; a value changes only if the same diff appends a `## Revision` section with a new full machine block to that roll-up whose `total_usd` is the new value (an append, so no exception to the rule above)                                                                                                                                                                                                                                                                                                                                                   |
| L5    | Every relative link and anchor in `INDEX.md`, the roll-ups and their machine blocks resolves; anchors are GitHub's lowercase slugs (`## 2026Q3` is `#2026q3`); an issuer-year file has at most one `## YYYYQn` heading per quarter                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| L6    | `INDEX.md` links every roll-up and every issuer-year file                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| L7    | Every extract has `- Retrieved:` (UTC, not later than now plus 10 minutes), `- Original URL:`, `- Archive URL:` (a web.archive.org snapshot of that page taken within 24h) and a verbatim quote; a field written in another form fails as the wrong form                                                                                                                                                                                                                                                                                                                                                                                                                  |
| L8    | Each newly added archive URL answers a HEAD request. Redirects are followed only to the same capture timestamp (another scheme, host or `id_`-style modifier); a redirect to another timestamp fails (the recorded snapshot does not exist; Wayback sent its nearest capture), as does one off the snapshot or more than 5 hops; if web.archive.org is unreachable, archive.org's availability API must return exactly the recorded snapshot timestamp. A network error fails (HTTP 429 is reported as rate-limited: retry later). Progress for each URL goes to stderr. A `Re-archive:` note in the same commit excuses only a confirmed dead snapshot (HTTP 404 or 410) |
| L9    | Each roll-up has one or more fenced `yaml` machine blocks (no front-matter); every block is validated on its own and recomputes exactly (decimal, half-to-even) to its `total_usd`; the last block is current, and the CSV value must equal its `total_usd`; each component anchor is `issuers/<its issuer>/<year>.md#<quarter slug>`; optional `cross_checks` name another published aggregate (name and url only, never a figure)                                                                                                                                                                                                                                       |
| L10   | Every file is UTF-8 text with no byte-order mark and at most 1 MB                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| L11   | `catalog.json` matches its schema (it lists a `base_money` series; each series has a semver `version`, a known data `license` and a `basket` of issuer ids) and points at files that exist                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| L12   | Issuer files live only at `issuers/<ISS>/<YYYY>.md` with `<ISS>` an upper-case id in the catalog basket, or exactly `FX` (`issuers/FX/` holds FX-rate sources); roll-ups only at `evidence/base_money/YYYYQn.md`; research logs only at `research/base_money/YYYYQn.md`; all patterns are exact and case-sensitive; any other file under `issuers/`, `evidence/` or `research/` (any extension, or none) fails, except `.gitkeep`                                                                                                                                                                                                                                         |

## Versions

Each series in `catalog.json` carries a semver `version` (base_money starts at `0.1.0`). Every row published under one version uses one basket of issuers, listed in the series' `basket`. A basket change is a major version bump plus a git tag, so a consumer can always tell which rows are comparable.
