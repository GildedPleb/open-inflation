# Banco Central do Brasil (BCB)

- **Official name:** Banco Central do Brasil
- **Country or currency area:** Brazil
- **Currency:** Brazilian real, BRL
- **What it is:** Brazil's central bank; in its own words, "O Banco Central do Brasil tem o objetivo fundamental de assegurar a estabilidade de preços".
- **Official website:** [bcb.gov.br, English](https://www.bcb.gov.br/en)
- **Data pages used here:** [SGS time-series pages](https://www3.bcb.gov.br/sgspub/) (series 20306 and 1788) · [SGS JSON API, series 20306](https://api.bcb.gov.br/dados/serie/bcdata.sgs.20306/dados?formato=json)

## What we measure

SGS 20306 "Reserve Money - Monetary Authority" / "Passivo Monetário - Autoridade Monetária". Its convention is unconfirmed, so BCB is excluded from the total and counted only as a reference value for coverage; SGS 1788 is an alternative definition, never adopted. See [Per-issuer definitions](../../../docs/methodology/base_money.md#per-issuer-definitions).
