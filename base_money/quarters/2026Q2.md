## What's left out

**Banco Central do Brasil (BCB)** is not in the total. Its reserve money (series SGS 20306) is published, but we could not confirm from a BCB primary page whether it is an end-of-month or an average figure; SGS 20306 stays BCB's reference series. For the coverage figure only, it is counted at BRL 1,399,128,000,000 (June 2026) × 0.19496164519554068128 USD per BRL (1 / [5.129214 BRL per USD](../FX/2026.md#fx-2026q2-brl)) = $272,776,296,719 from the [SGS values page](../issuers/BCB/2026.md#bcb-sgs-20306-reserve-money---monetary-authority-jun2026-sgs-values-page-retrieved-2026-10-22) (the [SGS JSON API](../issuers/BCB/2026.md#bcb-sgs-20306-reserve-money---monetary-authority-jun2026-sgs-json-api-retrieved-2026-10-22) gives the same figure).

Coverage = $22,041,431,082,440 ÷ ($22,041,431,082,440 + $272,776,296,719) = 98.77756672202…%, shown as 98.78%. The basket's floor is 94%, so the quarter is published. (The eight issuers' individually rounded shares add up to 98.79%; the 0.01 gap is display rounding.)

**What this means for growth rates.** Because BCB is missing, this total is lower than the full basket by BCB's amount. A growth rate into or out of this quarter is only like-for-like against a quarter that also leaves BCB out. [2026Q1](2026Q1.md) does ($22,365,865,359,611); this quarter is $324,434,277,171 (1.451%) lower, a like-for-like comparison within the same basket, partly driven by exchange rates, since each balance is converted at the market rate on its own count date.

## Checks and possible conflicts

No source disagrees with an adopted figure.

- **India.** A later RBI supplement, of 24 Jul 2026, prints reserve money of 5,232,272 (₹ crore) on 15 July with a fortnight change of −24,093 "with respect to June 30, 2026". So 30 June = 5,232,272 + 24,093 = 5,256,365, the same as the [adopted figure](../issuers/RBI/2026.md#rbi-reserve-money-2026-06-30-wss-2026-07-10): no revision. Its own figure falls in July, outside the quarter, so it is a check only and is never summed.
- **Euro area.** The ECB press release headline, EUR 3,980.3 billion ([extract](../issuers/ECB/2026.md#ecb-press-release-base-money-headline-statement-2026-06-26-published-2026-06-30)), agrees with the summed items (3,980,253 EUR millions) to its rounding.
- **Russia.** The narrow definition of the monetary base, 21,408.0 billion rubles on 1 July 2026 ([extract](../issuers/CBR/2026.md#cbr-monetary-base-narrow-definition-01072026-retrieved-2026-10-22)), is a different definition, not a conflict. Required reserves are 495.7 in the narrow table and 588.4 in the broad file for the same date; the Bank of Russia's footnotes do not explain the difference, so it is recorded as unexplained.
- **Brazil.** The narrow monetary base, SGS 1788, June 2026: 431.100.998 (BRL thousand) = BRL 431,100,998,000 ([extract](../issuers/BCB/2026.md#bcb-sgs-1788-monetary-base-end-of-period-balance-jun2026-sgs-values-page-retrieved-2026-10-22)); the JSON API gives the same value. It is an alternative definition, 0.308 of SGS 20306: never summed and not BCB's reference value.
- **Other published aggregates.** None compared this quarter.
