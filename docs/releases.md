# Versions and releases

Each series in `catalog.json` carries a semver `version` (base_money: `0.1.0` for the skeleton, `1.0.0` from its first published row, basket v1). The series' `baskets` list every basket of issuers ever used, versions 1..n, each with its coverage `floor_pct`; a committed basket entry is immutable as a whole (its issuers, their order and its `floor_pct`) and is never edited or removed. A basket change appends a new basket, with a major version bump plus a git tag. One CSV may hold rows computed under different baskets: each row keeps the basket in force when its quarter was first published, unless an appended Revision adds a newly evidenced issuer, which moves the row to the newer basket. The basket is recorded in the roll-up's machine block as `basket_version` (implied 1 while only one basket exists) and named in each [quarter file](../base_money/), which warns that rows on different baskets are not strictly comparable.
