# What lint enforces

`bun run lint` runs every check below on the working tree alone; it reads no base commit, and `--base <ref>` or `$LINT_BASE` is accepted and ignored (see [running the checks](running.md#lint)). It makes no network calls, ever.

## Checks

### L1

`base_money/base_money.csv` is UTF-8 with no byte-order mark, LF line endings and a final newline; header exactly `date,value,evidence_id`; quarter-end ISO dates, strictly ascending; non-negative integer USD values.

### L2

Every `evidence_id` is `base_money/quarters/YYYYQn.md`, exists, and matches the row's quarter.

### L3

Retired until v1: nothing is locked before the first v1 release. Committed headings, extract lines, machine blocks, CSV rows and catalog baskets may change like any other text; only the checks below apply to the result. History locks will be rebuilt for v1.

### L4

Retired until v1, like L3: there is no append-only or value lock.

### L5

Every relative link and anchor in `README.md`, `base_money/README.md`, the issuer and FX folder READMEs, `AGENTS.md`, every `docs/**.md`, the quarter files and their machine blocks (component and `reference_values` anchors, written from the repository root) resolves; anchors are GitHub's lowercase slugs (`## 2026Q3` is `#2026q3`) or an explicit `<a id="..."></a>` in the target file outside code fences (the FX table row anchors); an issuer-year file has at most one `## YYYYQn` heading per quarter. A quarter file's reader text has no absolute `http://` or `https://` URL: it links only repo-relative paths (the extracts, the issuer README, other quarters), and the source and archive URLs live only in the issuer extracts and the FX rate tables, so a quarter file has no Sources table. Each line with such a URL fails, in prose, tables and non-`yaml` fences alike; text inside the fenced `yaml` machine blocks is exempt. `audit` and `verify` read source and archive URLs from the issuer extracts only, never from quarter files or the FX rate tables.

### L6

`base_money/README.md` (the quarter list) links every quarter file, and once `README.md` carries its generated blocks, its table links every quarter file. `docs/README.md` is the docs index: once any `docs/**.md` exists, it exists and links every other `docs/**.md` and `AGENTS.md`.

### L7

Every extract has:

- `- Retrieved:` (UTC, not later than now plus 10 minutes).
- `- Original URL:`.
- One or more numbered archive lines, `- Archive URL:`, `- Archive URL 2:`, `- Archive URL 3:`, ... in that order, no URL twice. Each is an archive capture: a Wayback snapshot `https://web.archive.org/web/<14-digit timestamp>/<URL>` (a real time; the URL is the Original URL or another archive URL of the extract, compared percent-decoded per component, since Wayback writes `/` in a query as `%2F`, and a malformed `%` escape fails), an archive.today capture (`https://archive.ph/<id>`, `https://archive.today/<id>` or `https://archive.is/<id>`, or the dated form `https://<same hosts>/<YYYYMMDDhhmmss>/<URL>` with a real timestamp and such a URL) or a Ghostarchive capture (`https://ghostarchive.org/archive/<id>`). Any other host, a self-hosted copy included, fails. How many are needed is L16.
- At most one `- Capture check: YYYY-MM-DD`, the last date every link was confirmed live and showing the number (on or after the UTC date of Retrieved, not after today). Only when the original is gone does it carry a note, `- Capture check: YYYY-MM-DD; <the evidence that the original cannot be re-found>.`, non-empty text ending with a period.
- A verbatim quote.
- `- As of:` (the observation date): `YYYY-MM-DD` or `YYYY-MM` (a real date), optionally followed by one parenthetical note to the end of the line. Under a `## YYYYQn` heading it falls inside that quarter (a month is in it if the month is). An issuer with `as_of_convention: "start_of_day"` in the catalog must use exactly the first day of the next quarter (its start-of-day stock is the quarter-end stock; no other date passes). As of (a `YYYY-MM` As of counts as that month's last day) is not after the UTC date of `- Retrieved:`.

`- Retrieved:` is the time the figure was first seen and never changes. An extract also may carry `- Rejected source: <what>: <reason>.` (a source considered and rejected; both parts non-empty, no URL; outside an `###` extract block it fails) and `- Note YYYY-MM-DD: <text>.` lines (a real date, non-empty text ending with a period). Beyond the template's fields, the numbered Archive URL lines and Capture check, those are the only line types (there is no archive-attempt, audit or re-archive line): any other `- <Label>:` line in an extract (outside code fences) fails, an undated `- Note:` included. An extract whose `- Notes:` line converts at an older rate (it names H.10, an official rate or a quarter-end rate) needs a dated `- Note YYYY-MM-DD:` line in the same extract saying that conversion is superseded or that the conversion above is not used (the FX table is the rate the total uses). L7 does not apply to the FX rate tables (`base_money/FX/<YYYY>.md`): they are not extracts and are not archived (L9 checks them).

### L8

Lint makes no network calls: it checks link form only (L7, L16). Whether the links are live and show the number is `bun run link-check` (see [Link check](running.md#link-check)), a local research script and not a merge gate. `bun run verify` checks each archive URL the diff adds once; a dead snapshot (HTTP 404 or 410) fails, and the fix is to cite another capture. A URL it cannot decide is a no verdict, not a failure, and is listed after the summary line `archive.today (distinct URLs): N verified, M unverified (R rate-limited, B blocked[, U unconfirmed][, O offline])` or its `ghostarchive (distinct URLs)` twin; a run with any such URL and no failure exits 3 (incomplete, not clean). What verify asks each archive and every verdict are in [Verify](running.md#verify) and [Archive host quirks](running.md#archive-host-quirks).

### L9

Each quarter file has one or more fenced `yaml` machine blocks (no front-matter), one per vintage; the last is current. Every block is validated on its own:

- Each component's and each reference value's USD is `local_value` × `fx_rate`, computed exactly and rounded half-to-even to a whole dollar, and `total_usd` is the sum of those whole dollars.
- A USD `local_value` with a decimal point (more precise than $1, `1000.0` included) fails, and a `local_value` in any currency is exact with no leading zero (`0123` and `00.5` fail; a plain `0` and `0.5` are allowed).
- The last block is current, and the CSV value must equal its `total_usd`.
- Each component anchor is `base_money/issuers/<its issuer>/<year>.md#<quarter slug>`.
- `exclusions` entries are `{issuer, reason}`, both required, and components + exclusions list every issuer of the block's basket exactly once (never in both, never an issuer outside the basket).
- Every `fx_rate` in `components` and `reference_values` is `"1"` for USD and otherwise equals, as a string, the rate derived from that currency's row of the FX table under the quarter's heading in `base_money/FX/<YYYY>.md` (Rate itself for `USD per <CCY>`; 1 / Rate rounded half-to-even to exactly 20 decimal places for `<CCY> per USD`; exact string match; no row, more than one, or an invalid row fails; the current block is checked against the table).
- `basket_version` (a positive integer naming a catalog basket, written plainly: `1`, not `"1"`, `1.0`, `1e0`, `0x1`, `01`, `+1` or `!!int 1`) is optional while the catalog lists one basket (absent means 1) and required on every block once it lists more; the block is checked against its own basket.
- `reference_values` (`{issuer, anchor, local_currency, local_value, fx_rate}`, exactly one per excluded issuer, also needing FX table rows, never counted in `total_usd`) and `coverage_pct` (a string with exactly 2 decimals) are required in every block: coverage = Σ components ÷ (Σ components + Σ references) × 100 over those whole-dollar figures, rounded once half-to-even to 2 decimals, must match.
- The exact coverage of the whole-dollar figures (the ratio itself unrounded) must be at least the basket's `floor_pct` (a true floor: 93.995 fails a 94 floor though it rounds to 94.00).
- Optional `cross_checks` name another published aggregate (name and url only, never a figure).

The quarter's reader table (the first table with `Issuer`, `Local amount`, `FX rate` and `USD` columns) equals the current block: one row per component, the Issuer cell linking that issuer's README (`../issuers/<ISS>/README.md`), with the issuer taken from the link, `<CCY> <amount>` equal to `local_currency` and `local_value`, the FX cell `X USD per <CCY>` (equal to `fx_rate`), `X <CCY> per USD` (giving `fx_rate` by the FX rule) or `none ...` for USD, the USD cell the component's whole dollars (`$1,234`), and the `**Total**` row `total_usd`. L9 strips each cell's link and compares the text, then checks the links, resolved from the quarter file. The USD cell must link the issuer's adopted extract (the `###` extract with `- Adopted: yes`) inside the section the component's anchor names, in the anchor's file, e.g. `[$5,488,400,000,000](../issuers/FED/2026.md#fed-h6-monetary-base-2026-06-release-2026-07-28)` for the anchor `base_money/issuers/FED/2026.md#2026q2`. The quarter heading itself, another extract, another issuer's or another quarter's extract, or no link fails. For a non-USD row, the FX cell must link that currency's FX table row (`../FX/<YYYY>.md#fx-<yyyyqn>-<ccy>`). A USD row's FX cell has no link.

The FX rate tables (`base_money/FX/<YYYY>.md`) are supporting data: market closes on each report's count date, regenerable and not archived. An FX year file is its `#` title, at most one non-blank preamble line, then its quarter tables; more preamble lines before the first `##` heading or table fail (the sources and rules live in `base_money/FX/README.md`). Under each `## YYYYQn` heading (a quarter of the file's year) is a table with `Issuer`, `Report count date`, `Date in report` (the column right after `Report count date`), `Date rule`, `Rate date`, `Pair`, `Rate` and `Source` columns (other columns, such as a cross-check, are allowed), with exactly one row per non-USD currency of that quarter's current machine block (`components` and `reference_values`); a missing row, a second row for a currency or a row for a currency the block does not use fails. Each row:

- Issuer: opens with the row anchor `<a id="fx-<yyyyqn>-<ccy>"></a>` and links `../issuers/<ISS>/README.md`, where `<ISS>` is the issuer reporting that currency in the current block.
- Report count date: links that issuer's adopted extract (`- Adopted: yes`; for a reference value, also `- Adopted: no (reference-only ...)`) under the quarter's heading in `base_money/issuers/<ISS>/<YYYY>.md`; the cell's text with the link removed equals the extract's `- As of:` value or starts with its leading date (`2026-07-01 (start of day)` for `2026-07-01`).
- Date in report: one non-empty double-quoted string, such as `"as at 26 June 2026"`, that appears exactly in the linked extract's quote (its `>` lines or a fenced `text` block).
- Date rule and Rate date: `same day` (Rate date = count date), `month average` (a `YYYY-MM` count date; the Rate date starts with it), `prior close` (the day before the count date) or `last close before` (before the count date and at most 4 days earlier).
- Pair: `<CCY> per USD` or `USD per <CCY>`, naming the row's currency. Rate: a positive plain decimal `^\d+(\.\d+)?$`.
- Source: exactly one `http(s)` link.

### L10

Every file is UTF-8 text with no byte-order mark and at most 1 MB.

### L11

`catalog.json` matches its schema (it lists a `base_money` series; each series has a semver `version`, a known data `license` `baskets` `[{version, issuers, floor_pct}]` with versions 1..n in order, non-empty unique upper-case issuers and a floor from 0 to 100 with at most 2 decimals, and an optional `issuers` list of `{id, as_of_convention?}` with unique ids from the baskets and `as_of_convention` only `"start_of_day"`); each series' `path` is a repo path ending in `.csv` (whether it exists is L19) and its `methodology` file exists.

### L12

Files under `base_money/` live only at `base_money/base_money.csv` (the series), `base_money/components.csv` (the components CSV), `base_money/README.md` (the quarter list), `base_money/quarters/YYYYQn.md`, `base_money/issuers/<ISS>/<YYYY>.md` with `<ISS>` an upper-case id in any catalog basket version, `base_money/issuers/<ISS>/README.md` (the bank's static facts, its quarter table and its year list), `base_money/issuers/<ISS>/<ISS>.csv` (the issuer's components CSV, named after its folder), `base_money/FX/<YYYY>.md` (the FX rate tables; `FX` is a folder, not an issuer) and `base_money/FX/README.md` (optional; L13 requires the issuer READMEs); all patterns are exact and case-sensitive; any other file under `base_money/` (any extension, or none) fails, except `.gitkeep`. Top-level `issuers/`, `evidence/` and `research/` folders are not used: any file in them other than `.gitkeep` fails. A `base_money.csv` at the repository root fails.

### L13

`README.md`'s generated blocks (`latest`, `table` and `yoy-notes`, between their `<!-- BEGIN GENERATED ... -->` and `<!-- END GENERATED ... -->` markers) equal what `bun run readme` writes from `base_money/base_money.csv`, each quarter file's last machine block, the adopted extracts' Status lines and `catalog.json`: the value in trillions (half-to-even, 2 dp), YoY per the rule below, coverage, the excluded issuers, the catalog version and update date. Every basket issuer with a year file has a `base_money/issuers/<ISS>/README.md` (the FX one is optional). Each issuer or FX folder README has a `## Years` heading. The lines under it, up to the next blank line, equal `- [YYYY](YYYY.md)` for every year file in that folder, newest first, or `No years yet.` when there are none. Everything else in the README (the bank's facts) is free text and is not checked, except the `## Quarters` table (L17). Outside the generated blocks, every `NN.NN%` figure in `README.md` equals the latest quarter's `coverage_pct` (the front page states one coverage figure). A hand-edited number, a removed marker, a missing `## Years` heading, or a year list missing a year, listing an extra year or out of order fails; the fix is `bun run readme`. The check is skipped only while an input cannot be read, which L1, L2, L9 or L11 report. YoY is (value / value four quarters earlier − 1) × 100, exact, half-to-even to 1 dp, always signed except `0.0%` (`+3.2%`, `-1.4%`, `0.0%`), shown only when that earlier quarter is in the CSV and has the same basket version and the same included issuers; otherwise `—¹` (no year-ago quarter) or `—²` (basket or coverage change), `¹` taking precedence. A figure (never a dash, the Latest line or a dollar total) carries `ᵖ` when any component of either quarter has a provisional status. The notes block holds, in the order `¹`, `²`, `ᵖ`, each its own paragraph and only when a cell needs it: `¹ No year-ago quarter yet: <quarters>.`, `² Not like for like: a year earlier used a different basket or set of banks: <quarters>.` and `ᵖ Uses a provisional bank figure that may be revised: <quarters>.`, each listing its quarters newest first.

### L14

The docs agree with the rules. In `AGENTS.md` and every `docs/**.md` (outside code fences), a backticked repo path (two or more segments ending in a file extension or `/`, placeholders such as `<ISS>` and `YYYY` and the retired L12 roots excepted) names a file or folder that exists. A machine-block anchor in `docs/methodology/` starts with `base_money/`, the form L9 requires (an anchor starting issuers/ or FX/ fails). None of these retired terms appears in `README.md`, `AGENTS.md` or `docs/**.md` other than this file: "failed-attempts block", "FX-rate extract", "adopted FX extract", "quarter-end exchange rate", "Components link". The layout lists in `docs/running.md` and `AGENTS.md` name every L12 path pattern. `docs/methodology/base_money.md` has a basket table with a `Share of the basket, <YYYYQn>` column for the latest quarter in the CSV, one row per issuer of that quarter's current machine block (components and reference values), each share the issuer's whole-dollar USD over their sum × 100, half-to-even to 2 decimals.

### L15

Evidence states the fact for a cold reader. No line of a `base_money/**.md` file names team, review or migration history (`PR #<n>`, `Probe`, `PREREAD`, "archive log" or "moved from the … quarter file") or archiving history: which archive was tried, failed or blocked (`Archive attempt`, `attempted <YYYY-MM-DD>`, "Archiving error" or "Archiving note", `CAPTCHA`, resubmit or resubmission, `Re-archive`, `Link audit <YYYY>-`). The evidence cites the live links only. Verbatim source quotes (`>` lines and fenced `text` blocks) are exempt; every other line counts, committed or not. A quarter file's rejected-source bullet (under a heading containing "rejected") may not name an issuer that records a `- Rejected source:` line under its extracts for that quarter: issuer-specific rejections live only under the extract.

### L16

Two live links per figure, checked statically. Every adopted extract (`- Adopted: yes`) whose fields pass L7 has a `- Retrieved:` line and two links that show its number: the Original URL plus at least one Archive URL, or, when the original is gone (the Capture check carries a note giving the evidence), at least two Archive URLs. Extra links stay. Lint cannot tell whether a link is live; `bun run link-check` does, and `--write` sets the Capture check date (an extract not yet confirmed has none).

### L17

Generated outputs. Once `README.md` has generated markers (or `base_money/components.csv` exists), each of these equals, byte for byte, what `bun run readme` writes; a finding names the file and the line of the first difference and says to run `bun run readme`:

- `base_money/components.csv` (columns and units: [Components CSV](methodology/base_money.md#components-csv)): header `date,quarter,issuer,as_of,convention,status,local_currency,local_value,fx_rate,usd_value,evidence_id`, then one row per CSV quarter and component of its roll-up's last machine block (excluded issuers get no row), oldest quarter first and in basket order within a quarter. `issuer`, `local_currency`, `local_value` and `fx_rate` are the machine block's; `usd_value` is `local_value` × `fx_rate` rounded half-to-even to a whole dollar; `evidence_id` is the adopted extract the component's anchor resolves to (`path#slug`, exactly one), and `as_of` (the leading `YYYY-MM-DD` or `YYYY-MM`), `convention` and `status` (`final`, `provisional`, `revised` or `as published`, the leading words) come from that extract's `- As of:`, `- Convention:` and `- Status:` lines. An extract missing one of them fails, as does a Convention with a comma or a double quote: no field is ever quoted.
- `base_money/issuers/<ISS>/<ISS>.csv`, for every issuer folder with a year file: the same header and that issuer's rows (header only when it has none). A copy for an issuer with no year file fails.
- Each quarter file's reader table has a `YoY (local; Total in USD)` column (an older `YoY…` header is replaced in place): each issuer's YoY in its local currency (its `local_value` against its own a year earlier: `—¹` when the year-ago quarter is not in the CSV, `—²` when the bank is not a component in either quarter or its currency changed) and the total row's YoY (the front page's cell). Right under the table sits the line `YoY: each bank's change is in its own currency, so exchange rates don't move it; the Total's is in US dollars.`, then the footnotes the column's cells need, each its own paragraph, in the order `¹ No year-ago quarter yet: the series has no <year-ago quarter>.`, `² Not like for like with <year-ago quarter>: <items>.` (in table order, joined by `; `: `<ISS> left out this quarter`, `<ISS> left out in <quarter>` (or `not in the basket in <quarter>` when the issuer was not in that quarter's basket at all), `<ISS> changed currency from <OLD> to <NEW>`, `Total: different basket or set of banks`) and `ᵖ Uses a provisional bank figure, from this quarter or a year earlier, that may be revised.`.
- The quarter table in `base_money/README.md` (the lines under its `## Quarters` heading, up to the next blank line: the header `| Quarter | Count date | Total (USD) | YoY (USD) | Exact total (USD) |`, its alignment row, then one row per quarter, newest first, `| [YYYY&nbsp;Qn](quarters/YYYYQn.md) | <date, YYYY&#8209;MM&#8209;DD> | <$X.XXT, or $X.XB under $1T> | <the front page's YoY cell> | <value, comma-grouped, no $> |`; the quarter and date keep to one line at phone width, with `&nbsp;` for the space and `&#8209;` (non-breaking hyphen) for each hyphen, since GitHub strips CSS) and, under it, the line `Total is rounded; Exact total is to the dollar.` then the front page's YoY notes, word for word. When any listed quarter leaves out a basket issuer, a last `Coverage` column reads `<coverage_pct>%; left out: <ISS>, ...` on that row and `all banks` on the others, and a quarter missing between two present ones is the row `| YYYY&nbsp;Qn | — | — | ... |`.
- Each issuer README's `## Quarters` section, right after the facts (before the README's first other `## ` heading, so `## Years` stays last): an intro line, then a table of every CSV quarter, newest first: `| Quarter | Count date | Amount (<CCY>) | Status | <PAIR> | USD | YoY (local) |`. Count date is the extract's `as_of`; Amount is the exact `local_value`, comma-grouped and linked to the adopted extract; Status is the extract's, as stored; the FX cell is the FX table's own Rate, verbatim, linked to its FX row (`—` for a USD row or when there is no single FX row, which L9 reports); USD is `usd_value` as `$X.XXT` from $1 trillion, else `$X.XB` (half-to-even); YoY is in the bank's currency, with `ᵖ` (never on Amount) when either end is provisional. The headers take the newest counted row's currency and pair; a row in another currency or pair carries its unit in the cell. A bank whose rows are all in USD has no pair or USD column. A quarter the bank is not counted in reads `left out: <reason>` (or `not in the basket`) with dashes. Then its footnotes (`¹ No year-ago quarter yet: <quarters>.`, `² Not like for like with a year earlier: <quarter> (<cause>), ...`, `ᵖ This quarter's or the year-ago figure is provisional, so the bank may revise it.`), each its own paragraph with the `²` items in one paragraph, newest first; then the definitions, each its own paragraph: the Count date definition when a count date is a `YYYY-MM` month: `Count date: the date the bank's figure counts, as the bank gives it.` then `YYYY-MM means the figure is the bank's average for that month.` for a bank whose basis is `average` (FED, BOE, SNB) or `YYYY-MM means the bank's month-end figure, published without a day.` for `month-end` (PBOC, BOJ, RBI, BCB). The basis is `MONTH_BASIS` in `tools/scripts/lib/readme.ts`, keyed by issuer (SNB alone, per `MONTH_BASIS_OVERRIDE`: `YYYY-MM means the figure is the bank's average for that month (inferred; see [the SNB note in the methodology](<methodology>#per-issuer-definitions)).`), from the methodology's Convention column; `bun run readme` reports a problem (and L17 a finding) for a `YYYY-MM` count date at a bank with no basis there (ECB, CBR or any bank not listed), or whose extract's Convention (`monthly average`, `end-of-month stock`) says the other basis, and `[Status](<methodology>#status-and-vintages): the bank's own label.` followed by each status the table shows, its term in code formatting and then its meaning (`` `final`: the bank marks it final. ``, in the order `final`, `provisional`, `revised`, `as published`; the wording is `STATUS_TERMS` in `tools/scripts/lib/readme.ts`) and `Later changes are added as revisions, never overwritten.`; then `**Download:** [<ISS>.csv](<ISS>.csv), this bank's rows as data. What each column means, with units: [CSV columns and units](<methodology>#components-csv).`. `<methodology>` is the catalog's `methodology` file, relative to the README; `bun run readme` reports a problem when it lacks either heading, and L5 checks both links. The section is moved there if it sits elsewhere.

Each committed components CSV is also checked on its own: UTF-8 without a byte-order mark, LF line endings, a final newline, the exact header, 11 fields per row, well-formed fields, `usd_value` equal to `local_value` × `fx_rate`, one row per quarter and issuer, the order above, and (for `base_money/components.csv`) each quarter's `usd_value` sum equal to its `base_money/base_money.csv` value. YoY figures carry `ᵖ` when either end is provisional (for a bank, its own status; for a total, any component's); a dash never does. The check is skipped only while an input cannot be read, which L1, L2, L9 or L11 report.

### L18

Every CSV in the repo is cataloged: each tracked `*.csv`, wherever it sits, is the `path` of a `catalog.json` series. The finding names the CSV and says to add a series entry with that path. No CSV is exempt, by path, folder or name: a fixture or scratch CSV committed to the repo is listed or removed. Skipped while `catalog.json` is missing, not JSON or has no `series` list (L11 reports each).

### L19

Every CSV `catalog.json` lists exists: each series `path` is a file in the repo. The finding is on `catalog.json` and names the path; the fix is to correct the path or drop the entry. Skipped like L18.
